## 项目背景

随着全球新能源汽车市场的快速发展，电动汽车（EV）已成为汽车产业转型升级的重要方向。华盛顿州作为美国新能源汽车普及度最高的州之一，拥有丰富的车辆登记数据，为研究新能源汽车市场趋势、用户偏好和产品特征提供了宝贵的数据基础。

本项目基于华盛顿州135,038条新能源车辆登记数据，融合从车主在线评论中提取的7大AI体验特征，构建了从数据清洗、SQL建模、Python分析到Excel报告、HTML交互式看板的全链路数据分析平台。

### 研究目标

1. **市场趋势分析**：揭示新能源汽车注册量、品牌份额、车型分布的时空演变规律
2. **用户体验挖掘**：从车主评论中提取AI体验特征，分析智驾、内饰、续航等维度的用户满意度
3. **保值率预测**：构建机器学习模型，预测新能源汽车二手价格，识别关键影响因素
4. **业务洞察输出**：将数据分析结果转化为可落地的业务建议，推动产品优化和市场策略调整

### 数据来源

- **车辆登记数据**：华盛顿州交通部公开的新能源车辆登记数据集（135,038条，17个字段）
- **AI体验特征数据**：从车主在线评论中通过NLP情感分析提取的7大体验维度评分
- **时间跨度**：2010-2024年车型年份
- **地理覆盖**：华盛顿州39个郡，181+个邮政编码区域

## 功能特性

- **全栈技术栈**：SQL + Python + Excel + HTML，覆盖数据工程到可视化全流程
- **星型数据模型**：SQLite构建4维度表+1事实表的标准星型模型，含索引优化
- **AI体验特征融合**：从车主评论中提取7大AI体验维度，与车辆基础数据关联分析
- **交互式HTML看板**：6大模块+保值率预测模拟器，纯前端实现，无需后端
- **自动化Excel报告**：6工作表+图表+数据筛选，一键生成
- **业务导向分析**：5大核心指标拆解+4大业务痛点+18项分层建议+7项行动方案
- **机器学习建模**：随机森林保值率预测模型，R2 Score = 0.7075
- **完整分析笔记本**：6个Jupyter笔记本，覆盖数据探索到模型解释全流程

## 核心发现

1. **特斯拉主导市场**：特斯拉占比超过50%，Model 3和Model Y最受欢迎
2. **BEV增长迅速**：纯电动汽车占比逐年提升，2023年超过80%
3. **续航里程提升**：平均续航从2015年约80英里提升到2023年约250英里
4. **品牌效应显著**：品牌是影响保值率的最重要因素（0.303）
5. **AI体验关联**：充电便利性和智能驾驶满意度与车辆价格正相关
