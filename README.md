# EV-Insight-Pro | 新能源汽车数据智能分析平台

> 基于华盛顿州135,038条新能源车辆登记数据，融合AI体验特征，构建从数据清洗、SQL建模、Python分析到Excel报告、HTML交互式看板的全链路数据分析项目。


## 项目背景

随着全球新能源汽车市场的快速发展，电动汽车（EV）已成为汽车产业转型升级的重要方向。华盛顿州作为美国新能源汽车普及度最高的州之一，拥有丰富的车辆登记数据，为研究新能源汽车市场趋势、用户偏好和产品特征提供了宝贵的数据基础。

本项目基于华盛顿州135,038条新能源车辆登记数据，融合从车主在线评论中提取的7大AI体验特征，构建了从数据清洗、SQL建模、Python分析到Excel报告、HTML交互式看板的全链路数据分析平台。项目旨在深入挖掘新能源汽车市场规律，识别影响车辆保值率的关键因素，为车企产品设计、市场策略和用户服务提供数据驱动的决策支持。

### 研究目标
1. **市场趋势分析**：揭示新能源汽车注册量、品牌份额、车型分布的时空演变规律
2. **用户体验挖掘**：从车主评论中提取AI体验特征，分析智驾、内饰、续航等维度的用户满意度
3. **保值率预测**：构建机器学习模型，预测新能源汽车二手价格，识别关键影响因素
4. **业务洞察输出**：将数据分析结果转化为可落地的业务建议，推动产品优化和市场策略调整

### 数据来源
- **车辆登记数据**：华盛顿州交通部公开的新能源车辆登记数据集（135,038条，17个字段）
- **AI体验特征数据**：从车主在线评论中通过NLP情感分析提取的7大体验维度评分
- **时间跨度**：2010-2024年车型年份
- **地理覆盖**：华盛顿州39个郡，181+个邮政编码区域

## 项目亮点

- **全栈技术栈**：SQL + Python + Excel + HTML，覆盖数据工程到可视化全流程
- **星型数据模型**：SQLite构建4维度表+1事实表的标准星型模型，含索引优化
- **AI体验特征融合**：从车主评论中提取7大AI体验维度（智驾/内饰/续航/电池焦虑等），与车辆基础数据关联分析

- **自动化Excel报告**：6工作表+图表+数据筛选，一键生成
- **业务导向分析**：5大核心指标拆解+4大业务痛点+18项分层建议+7项行动方案

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 准备数据
将原始数据CSV放入 `data/raw/` 目录：
- `Electric_Vehicle_Population_Data.csv`（原始车辆登记数据）
- `ev_with_ai_features_real.csv`（AI体验特征数据）

### 3. 运行完整流水线
```bash
cd src/python
python main.py
```

### 4. 查看产物
- **HTML看板**：用浏览器打开 `dashboard/index.html`
- **Excel报告**：打开 `reports/excel/EV_Analysis_Report.xlsx`
- **SQL数据库**：`database/ev_analysis.db`（可用DB Browser for SQLite查看）
- **SQL脚本**：`src/sql/` 目录下的建表和分析查询

## 模型训练与预测

### 随机森林保值率预测模型
- **算法**: Random Forest Regressor（100棵树，最大深度15）
- **目标变量**: 指导价（Base MSRP）
- **特征**: 车龄、续航、年份、品牌、7大AI体验特征
- **评估结果**: R2 Score = 0.7075，MAE = $933
- **模型文件**: models/random_forest_model.pkl（384KB）

### 特征重要性 TOP 5
1. 品牌（make_encoded）: 0.303
2. 车龄（car_age）: 0.248
3. 车型年份（model_year）: 0.222
4. 续航里程（electric_range）: 0.204
5. 充电便利性（charging_convenience_mean）: 0.007

### 模型训练模块
- src/python/models/model_trainer.py - 模型训练、评估、保存、加载、预测
- 支持随机森林、梯度提升、线性回归、岭回归等多种算法
- 包含交叉验证、特征重要性分析、网格搜索等功能

## 核心发现

1. **市场爆发增长**：2021-2023年注册量年均增长35%，BEV占比从0%回升至78%
2. **品牌高度集中**：TESLA占46.9%市场份额，TOP5品牌占比超88%
3. **电池焦虑是核心痛点**：正向贡献95.18%，用户越焦虑越倾向有质保的品牌
4. **智能化成差异化竞争点**：智驾满意度进入TOP5重要特征，智驾好的品牌溢价明显
5. **车龄是最关键影响因子**：重要性0.25，每增加1年价格下降约15%
